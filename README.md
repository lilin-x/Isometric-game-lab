# Red Scarf Adventure — Isometric Game Lab

เกม 3D มุมมอง **Isometric** สไตล์ **low poly** สำหรับ **เรียนรู้การทำเกมตั้งแต่ศูนย์**
เขียนด้วย **Three.js + JavaScript ล้วน** (ไม่ใช้ game engine) ทุกโมเดลสร้างจากโค้ด ไม่มีไฟล์ 3D หรือไฟล์เสียงเลย

ตัวเอก "ไค" เด็กชายนักผจญภัยผ้าพันคอแดง ออกเดินทางจาก **เมืองโคมไฟ** สู่ **ป่าหลากสี** เพื่อปลุกศาลคริสตัล

> 📖 **หน้าสอนสำหรับมือใหม่:** [`docs/tutorial.html`](docs/tutorial.html) — อธิบายหลักการทำเกมทีละส่วน พร้อมแผนภาพและเดโมให้ลองกด

---

## เริ่มต้นใช้งาน

ต้องมี [Node.js](https://nodejs.org/) เวอร์ชัน 18 ขึ้นไป

```bash
npm install
```

```bash
npm run dev
```

เปิดเบราว์เซอร์ที่ `http://localhost:5173` แล้วกด **เริ่มผจญภัย**

| คำสั่ง | ทำอะไร |
|---|---|
| `npm run dev` | เปิดเซิร์ฟเวอร์สำหรับพัฒนา (แก้โค้ดแล้วหน้าเว็บรีเฟรชเอง) |
| `npm run build` | สร้างไฟล์สำหรับเผยแพร่ที่ `dist/` |
| `npm run build:single` | รวมทั้งเกมเป็นไฟล์เดียว `dist-single/index.html` (ส่งให้เพื่อนเปิดเล่นได้เลย) |
| `npm test` | รัน unit test ของระบบ stamina |

**ตัวช่วยทดสอบผ่าน URL**: `?level=forest` เริ่มที่ด่านป่า · `?skip` ข้ามหน้าแรก · `?debug` เปิดหน้าต่าง debug · `?nobloom` / `?noshadow` ปิดเอฟเฟกต์ถ้าเครื่องช้า
เช่น `http://localhost:5173/?level=forest&skip&debug`

## การควบคุม

| ปุ่ม | การกระทำ |
|---|---|
| `W A S D` | เดิน (ทิศอิงหน้าจอ) |
| คลิกซ้าย / `J` | ฟันเบา — กดต่อเนื่องได้คอมโบ 3 จังหวะ |
| ค้างคลิกขวา / `K` | ชาร์จ → ปล่อยเพื่อหมุนฟันรอบตัว (ยิ่งชาร์จนานยิ่งแรง) |
| `Space` / `Shift` | กลิ้งหลบ (อมตะช่วงสั้นๆ ระหว่างกลิ้ง) |
| `E` | คุยกับ NPC / ใช้ประตู / ปลุกศาล |
| `Esc` | พักเกม · `M` เปิด/ปิดเสียง · `F3` หน้าต่าง debug |

## ระบบเกม

- **ฟันเบา**: ใช้ stamina 12, damage 8–10 (จังหวะที่ 3: 12–14), ฟันได้ถี่
- **ฟันแรง (ชาร์จ)**: ใช้ stamina 20–40 และทำ damage 25–60 ตามเวลาที่ชาร์จ (เต็มที่ 1.2 วินาที) หมุนฟันรอบตัว
- **กลิ้งหลบ**: ใช้ stamina 20 อมตะช่วง 0.03–0.32 วินาทีของท่า
- **Stamina**: หยุดใช้ 1 วินาทีแล้วค่อยๆ ฟื้น 25/วินาที · ถ้า**หมดหลอด** จะติด cooldown 4 วินาที (มีวง loading เหนือหัว + หลอดลายทาง) แล้วฟื้นกลับมา**ครึ่งหลอด**
- **การแสดงผล**: ตัวเลข damage เด้ง, หยุดภาพแป๊บตอนฟันโดน (hit-stop), จอสั่น, มอนสเตอร์กระพริบขาวและกระเด็น, วงเตือนสีแดงก่อนมอนสเตอร์โจมตี
- **มอนสเตอร์ 3 ชนิด**: สไลม์ (กระโดดพุ่ง), เห็ด (ระเบิดสปอร์รอบตัว), โกเลมหิน (ทุบพื้น, ฟันเบาไม่สะดุ้ง ต้องใช้ฟันชาร์จ)

ปรับตัวเลขทั้งหมดได้ที่ไฟล์เดียว: [`src/config.js`](src/config.js)

│   ├── StateMachine.js  Finite State Machine
│   ├── Stamina.js       ระบบ stamina (pure logic มี unit test)

│   ├── Scarf.js         ผ้าพันคอปลิว (verlet rope)

│   ├── NPC.js           ชาวเมือง + แมว
│   ├── TrainingDummy.js หุ่นฟางซ้อมฟัน
│   └── Critters.js      ผีเสื้อ กระต่าย

## ลองแก้ดูเป็นการบ้าน 🛠️

1. เปลี่ยนสีผ้าพันคอของไคใน `src/models/humanoid.js` (ค้นหา `0xd63a2f`)
2. ทำให้ฟันเบาใช้ stamina 5 แล้วลองเล่นดูว่าเกมง่ายขึ้นแค่ไหน (`src/config.js`)
3. เพิ่ม NPC คนใหม่ในเมือง (`_spawnNPCs()` ใน `src/levels/TownLevel.js`)
4. เพิ่มสไลม์อีก 3 ตัวในป่า (`_spawnEnemies()` ใน `src/levels/ForestLevel.js`)
5. ทำมอนสเตอร์ชนิดใหม่ โดยสืบทอดคลาส `Enemy` แล้ว override `startWindup` / `startAttack`
